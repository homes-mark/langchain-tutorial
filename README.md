# LangChain 1.2 完整学习教程

一份由浅入深、可完全离线浏览、代码可运行的中文教程。覆盖从「链（Chain）」到「企业级智能体（Agent）」的完整演进路径。

## 快速开始

直接用浏览器打开 `index.html` 即可开始学习（无需联网，无任何外部依赖）。

## 教程结构

| 阶段 | 章节 | 内容 |
|------|------|------|
| 入门 | 01–04 | 环境搭建、链（Chain）、提示模板、记忆（Memory） |
| 进阶 | 05–07 | 检索增强生成（RAG）、工具调用、智能体（Agent） |
| 实战 | 08–10 | 企业级 Agent 实战、高级主题与生产化、附录 |

## 特点

- **学习路径清晰**：每章标注学习目标、前置知识、难度等级与建议顺序
- **代码可运行**：64+ 个 Python 代码示例，注明依赖版本，含预期输出
- **动手练习**：33 个由易到难的练习，附验证方法
- **误区与最佳实践**：性能、安全、可维护性提示贯穿全文
- **完全离线**：无 CDN、无外部字体，语法高亮为自写轻量实现

## 依赖版本

本教程以 **LangChain 1.2** 为准（`langchain-core` / `langchain`），采用新版 API（`create_agent`、`bind_tools`、`RunnableWithMessageHistory`）。

详见 `HANDOFF.md`（项目交接与决策记录）。
