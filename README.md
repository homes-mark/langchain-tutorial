# LangChain 1.2 由浅入深完整学习教程

> 一份面向 AI 应用开发者的中文 LangChain 教程：从确定性的链（Chain）出发，逐步掌握提示模板、记忆、RAG、工具调用和智能体（Agent），最终完成一个企业级 Agent 实战项目。

## 这个教程是为了什么？

大模型应用并不只是“调用一次模型 API”。要构建稳定、可维护的 LLM 应用，还需要理解工作流编排、上下文管理、知识检索、外部工具、错误处理、安全边界与生产部署。

本教程希望帮助读者：

- 建立从 Chain 到 Agent 的完整知识体系，理解不同范式解决的问题；
- 掌握 LangChain 1.2 的新版核心 API，而不是停留在已废弃的旧用法；
- 学会把提示词、模型、检索、记忆和工具组合成可测试的应用；
- 通过递进式实战项目，理解从 Demo 到生产系统还需要补齐哪些能力。

教程以概念演进为主线，既解释“是什么”，也说明“为什么这样设计”和“什么时候应该使用”。所有页面均可离线浏览，适合系统学习、课后复习或作为开发参考。

## 实战项目路线

实战部分以“电商智能客服”为例，分四个阶段逐步实现：

1. **单工具 Agent**——完成基础模型调用和工具循环；
2. **多工具协作**——接入订单、物流、优惠规则等多类工具；
3. **加入会话记忆**——支持有上下文的多轮客服对话；
4. **加入 RAG 与人工审核**——检索业务知识，并为敏感操作加入人工确认。

每个阶段都有明确目标、核心代码和验收标准，可以直接对照实现与检查。

## 学习方式

- 建议按“工作流 → 上下文 → 知识与工具 → Agent → 生产化”的顺序阅读；
- 每章包含学习目标、前置知识、代码示例、练习、常见误区与最佳实践；
- 页面支持阅读进度和完成状态标记，进度保存在浏览器本地；
- 所有样式和脚本均为本地资源，不使用 CDN，可完全离线阅读。

## 快速开始

克隆或下载本仓库，然后打开 [`index.html`](./index.html)：

```bash
git clone https://github.com/homes-mark/langchain-tutorial.git
cd langchain-tutorial
```

也可以直接双击 `index.html`，从教程首页开始。

## 适合谁？

- 想系统学习 LangChain 1.2，并理解 Chain、Memory、RAG、Tool 与 Agent 关系的开发者；
- 已经会调用 LLM API，但希望进一步构建完整 AI 应用的开发者；
- 需要复习 LangChain 新版 API、排查常见问题或准备 Agent 项目的人。

## 版本说明

教程以 `langchain` 和 `langchain-core` 的 **1.2.x** 为版本基准，使用 `create_agent`、`bind_tools`、`RunnableWithMessageHistory` 等新版 API，不使用已废弃的 `LLMChain` 或旧版 Memory 类。实际项目中请以所安装版本的官方文档为准。

更多制作说明与项目决策记录见 [`HANDOFF.md`](./HANDOFF.md)。
