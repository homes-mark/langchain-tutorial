关于本教程

LangChain 是一个用于构建 大语言模型（LLM）应用的框架。它的核心价值在于：把「模型调用」这件单一的事，扩展为「编排模型、数据、工具与外部系统的完整工作流」。本教程以 LangChain 1.2 版本为准（核心库为 langchain-core 与 langchain），所有代码均可直接运行。

💡 版本说明 LangChain 在 0.3 之后进行了大规模重构，将底层抽象拆分为独立的 langchain-core 包（BaseLanguageModel、Runnable、消息模型等），langchain 作为集成层。1.x 进一步强化了 create_agent、LangGraph 集成与标准化工具调用。本教程中的导入路径均以 1.2 的实际 API 为准。

核心概念与演进关系

整个教程围绕一条清晰的演进主线展开。理解这些概念之间的「依赖关系」，是掌握 LangChain 的关键：

  1. 提示模板 + 模型 → 构成最基本的调用单元。
  2. 链（Chain） 用 LCEL 把多个步骤串起来，实现多步流程。
  3. 在链的基础上叠加 记忆（上下文）、检索（外部知识）、工具（外部动作）三类能力。
  4. 智能体（Agent） 让模型自主决定「何时调用哪个工具、调用几次、何时给出最终答案」——它是链、记忆、检索、工具的集大成者。

前置知识

  • Python：掌握函数、类、类型注解（def f(x: int) -> str）、异常处理、pip 与虚拟环境。
  • LLM 基础概念：了解什么是 token、上下文窗口、temperature、system/user/assistant 消息角色。
  • 可选：基础的向量/嵌入（Embedding）直觉，RAG 章节会详细讲解。
⚠️ 开始之前 你需要一个可用的 LLM API Key（如 OpenAI、Anthropic，或国内可用的兼容端点）。本教程代码示例默认使用 ChatOpenAI，但你可以在 第 01 章 学习如何切换到任意兼容 OpenAI 接口的服务。

学习常见陷阱（提前避坑）

❌ 陷阱 1：死记 API，不理解原理 LangChain 版本迭代快，API 会变。关键是理解 Runnable/LCEL 的「输入输出类型匹配」这一底层逻辑，而非背具体类名。掌握原理后，任何版本都能快速上手。
❌ 陷阱 2：跳过「消息模型」直接学 Agent HumanMessage/AIMessage/ToolMessage 是所有高级特性（记忆、工具、Agent）的地基。地基不牢，后面会频繁被 KeyError、类型不匹配等问题卡住。
❌ 陷阱 3：只读代码不运行 本教程刻意设计成「可运行」。请务必在本地逐条运行、改参数、观察输出变化——这是唯一真正学会的方式。

如何使用本教程

  • 顺序学习：按 01→10 的顺序，每个页面末尾有「上一页 / 下一页」导航。
  • 动手优先：每个章节都有「动手练习」，请务必自己敲一遍代码，而不只是阅读。
  • 进度追踪：每个练习前有复选框，勾选状态会自动保存在浏览器本地（离线可用）。
  • 离线浏览：所有页面、样式、脚本均为本地文件，无任何网络依赖，可直接双击 index.html 打开。
