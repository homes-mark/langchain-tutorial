10.2 常用 API 速查

from langchain_openai import ChatOpenAI           # 模型
from langchain_core.prompts import ChatPromptTemplate   # 提示
from langchain_core.output_parsers import StrOutputParser # 输出解析
from langchain_core.runnables import (            # 编排
    RunnableLambda, RunnableParallel, RunnablePassthrough)
from langchain_core.messages import (              # 消息
    HumanMessage, AIMessage, SystemMessage, ToolMessage)
from langchain_core.tools import tool              # 工具
from langchain.agents import create_agent          # 智能体
from langchain_core.chat_history import InMemoryChatMessageHistory  # 记忆
from langchain_core.runnables.history import RunnableWithMessageHistory

常用组合模式

# 1. 基础链
chain = prompt | model | StrOutputParser()

# 2. RAG 链
chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt | model | StrOutputParser()
)

# 3. 并行
chain = RunnableParallel(a=chain_a, b=chain_b)

# 4. 带记忆
chain = RunnableWithMessageHistory(
    prompt | model,
    get_history,
    input_messages_key="input",
    history_messages_key="history",
)

10.3 常见报错与解决

报错原因解决
KeyError: 'xxx'链的输入键不匹配检查上一步输出键与下一步输入键，用 RunnableLambda 适配
ModuleNotFoundError集成包未安装按需安装 langchain-openai / langchain-community 等
AuthenticationErrorAPI Key 未配置或失效检查 .env 与环境变量
InvalidRequestError参数错误或超上下文检查 max_tokens、裁剪历史
RateLimitError请求过快加限流、重试、退避
Agent 无限循环无法收敛设 max_iterations、优化工具描述与 system_prompt

10.6 常用代码片段速查（Cookbook）

以下是最常用的几段「拿来即用」的代码模板，覆盖 80% 的常见需求：

# 1. 最简链
chain = ChatPromptTemplate.from_template("{x}") | model | StrOutputParser()

# 2. 结构化输出
result = model.with_structured_output(MyPydanticModel).invoke("...")

# 3. 带记忆的链
chain = RunnableWithMessageHistory(chain, get_history,
    input_messages_key="input", history_messages_key="history")

# 4. RAG 问答
rag = ({"context": retriever | fmt, "question": RunnablePassthrough()}
       | prompt | model | StrOutputParser())

# 5. 工具 + Agent
agent = create_agent(model, tools=[...], system_prompt="...")

# 6. 流式输出
for chunk in chain.stream(input):
    print(chunk.content, end="")

# 7. 并行
both = RunnableParallel(a=chain_a, b=chain_b)

# 8. 回退
robust = primary.with_fallbacks([backup])

# 9. 缓存
set_llm_cache(InMemoryCache())

# 10. 异步
result = await chain.ainvoke(input)

10.7 调试技巧速查

问题排查方法
链输入键报错打印 chain.input_schema 查看期望的输入结构
不知道中间输出了什么插入 RunnableLambda(print) 打印中间结果
模型调用了错误的工具检查工具的 docstring 是否清晰、是否与其它工具混淆
Agent 死循环打印 messages 历史，看它卡在哪个工具上
RAG 检索不到检查切分参数、嵌入是否一致、文档是否清洗
响应太慢用流式输出、并行、缓存、更小的模型
