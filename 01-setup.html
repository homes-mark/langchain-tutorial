01 环境搭建与快速上手

阶段一 · 入门 难度：入门 前置：Python 基础

学习目标

  • 安装 langchain 1.2 及依赖
  • 配置 API Key，完成第一个 LLM 调用
  • 理解消息模型与温度参数

前置知识

  • Python 虚拟环境与 pip
  • 环境变量的基本用法

1.1 安装

建议在虚拟环境中安装，避免污染全局环境。以下命令以 Windows/macOS/Linux 通用。

# 创建并激活虚拟环境
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
# source .venv/bin/activate

# 安装 LangChain 1.2（含核心与常用集成）
pip install "langchain>=1.2,<2.0" "langchain-core>=1.2,<2.0"

# 安装 OpenAI 集成（用于调用 OpenAI 或兼容端点）
pip install "langchain-openai>=1.0"
💡 依赖版本 本教程所有示例均在以下版本验证：langchain==1.2.x、langchain-core==1.2.x、langchain-openai==1.0.x、langchain-community==1.0.x。可用 pip show langchain 查看实际安装版本。

1.2 配置 API Key

不要将密钥硬编码在代码里，应通过环境变量管理。创建一个 .env 文件（并加入 .gitignore）：

# .env 文件内容
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.openai.com/v1   # 可选：国内兼容端点时填写

加载环境变量需要一个轻量库 python-dotenv：

pip install python-dotenv
⚠️ 安全提示 绝不把 API Key 提交到 Git 仓库。务必把 .env 加入 .gitignore。生产环境建议使用云平台的密钥管理服务（如 AWS Secrets Manager、Vault），而非环境变量明文存储。

1.3 第一个 LLM 调用

LangChain 的核心抽象是 BaseChatModel。下面创建一个聊天模型并调用：

import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()  # 读取 .env 中的变量

# 创建模型实例
model = ChatOpenAI(
    model="gpt-4o-mini",       # 模型名称
    temperature=0.7,           # 随机性：0 更确定，1 更有创造性
    # base_url=os.getenv("OPENAI_BASE_URL"),  # 使用兼容端点时取消注释
)

# 调用：传入一个消息列表
response = model.invoke("用一句话介绍你自己")
print(response.content)
我是一个由人工智能技术驱动的语言模型助手，
旨在帮助用户解答问题、提供信息和完成各种任务。

消息模型（Message Model）

聊天模型支持三种角色消息，这是理解后续所有高级特性的基础：

from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

messages = [
    SystemMessage(content="你是一位严谨的 Python 技术讲师，回答简洁准确。"),
    HumanMessage(content="什么是列表推导式？"),
]
resp = model.invoke(messages)
print(resp.content)
print(type(resp))  # langchain_core.messages.ai.AIMessage

1.4 关键参数

参数作用取值建议
temperature采样随机性代码生成 0–0.2；创意写作 0.8–1.0
max_tokens最大输出 token 数按任务估算，避免截断
model模型名称成本与能力权衡
timeout请求超时默认 600s，可调小
✅ 最佳实践 建议在 ChatOpenAI 之上再包一层 model.bind(...) 或自定义配置，将模型参数集中管理，方便后续替换模型或统一调参，避免散落在代码各处。

1.5 切换国内/兼容端点

如果你的服务使用兼容 OpenAI 接口的端点（如 DeepSeek、通义千问、Kimi、本地 Ollama 等），只需修改 base_url 和 api_key：

import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

# 以 DeepSeek 为例：兼容 OpenAI 协议
model = ChatOpenAI(
    model="deepseek-chat",                       # 换成目标模型名
    base_url="https://api.deepseek.com",         # 换成服务商端点
    api_key=os.getenv("DEEPSEEK_API_KEY"),       # 换成对应密钥
    temperature=0.7,
)

print(model.invoke("你好，请自我介绍").content)
💡 本地模型（Ollama） 想完全离线、免费调试？可以用 附录 提到的本地模型，配合 ChatOllama： 
from langchain_ollama import ChatOllama
model = ChatOllama(model="llama3.1", temperature=0)
需要先安装 pip install langchain-ollama 并在本地启动 Ollama 服务。

1.6 完整的项目初始化脚本

下面是一份可直接复制运行的初始化脚本，帮你一键搭好项目骨架（供后续章节复用）：

# init_project.py —— 一键初始化教程项目
import os
import subprocess
import sys

PROJECT = "langchain-tutorial-lab"

def run(cmd):
    print(f">>> {cmd}")
    subprocess.run(cmd, shell=True, check=True)

def main():
    # 1. 创建目录与虚拟环境
    os.makedirs(PROJECT, exist_ok=True)
    os.chdir(PROJECT)
    run(f"{sys.executable} -m venv .venv")

    # 2. 安装依赖（Windows 用 .venv\\Scripts\\pip）
    pip = ".venv\\Scripts\\pip" if os.name == "nt" else ".venv/bin/pip"
    run(f"{pip} install langchain langchain-core langchain-openai python-dotenv")

    # 3. 写入 .env 模板
    with open(".env", "w", encoding="utf-8") as f:
        f.write("OPENAI_API_KEY=sk-请替换为你的密钥\n")

    # 4. 写入 .gitignore
    with open(".gitignore", "w", encoding="utf-8") as f:
        f.write(".env\n.venv/\n__pycache__/\n*.pyc\n")

    print("\n✅ 项目初始化完成！")
    print("下一步：编辑 .env 填入真实 API Key，然后开始写代码。")

if __name__ == "__main__":
    main()
